# Internal OA open-source release gate

- [ ] Confirm ownership and written permission to publish.
- [ ] Do not copy production binaries, reverse-engineered proprietary implementations, or third-party assets.
- [ ] Remove all employee, contract, attendance, payroll, vendor, customer and asset data.
- [ ] Check all files and Git history for credentials, internal IPs, names and secrets.
- [ ] Review third-party dependencies and licenses.
- [ ] Run Java tests and dependency scans.
- [ ] Review screenshots and examples for personal information.
- [ ] Keep database dumps and attachments outside public repositories.
